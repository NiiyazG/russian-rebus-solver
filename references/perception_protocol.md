# Perception protocol

Before solving, create a literal inventory.

## Element types

- picture
- letter/syllable/token
- digit
- comma
- arrow
- pointing hand
- equality/replacement
- crossed **letter**
- crossed **whole token/card**
- note
- answer box
- regular sequence
- missing sequence member
- repeated/highlighted element

## Critical distinction: local crossing vs state crossing

### Local crossing
A cross/strike targets one letter inside a larger word or a specific index.
Default reading: delete/replace that local symbol.

### Whole-token crossing
A large X spans the complete token/card, such as `КО` or `ЗА`.
Possible reading: **state of existence** — "was / no longer is" — especially if the puzzle also contains an intact token or a missing sequence member.

Never classify these two cases as the same operator without testing both.

## Regular sequences

Whenever visible digits/letters form an obvious sequence:
1. infer expected range;
2. list missing members;
3. decide whether numbers are:
   - indices;
   - literal numbers;
   - an absence statement.

Example:
`1 2 3 4 6 7 8 9` → missing `5`.

## Phrase-level clues

Raise phrase-level mode if:
- multiple cards;
- whole-token states;
- contrast colors such as crossed red vs intact green;
- a sequence with a gap;
- no normal picture-word composition.

## Picture candidates

For each picture keep multiple names until operators resolve ambiguity.

## Tiny symbols

Count every comma, digit, cross, arrow, equality sign, and answer box. Do not silently ignore any strong visual cue.
