# Category modes

## LOGOPEDIC
Pictures can encode sounds:
ворона→КАР, корова→МУ, волк→У, комар→З, тигр→Р, кот→МЯУ, собака→ГАВ, лягушка→КВА.

## MUSICAL
Notes: ДО, РЕ, МИ, ФА, СОЛЬ, ЛЯ, СИ.

## THEMATIC
Use theme only as a ranking prior, never to override visual accounting.

## LITERARY
Allow proper names and multiword answers.

## CHESS
Distinguish a word rebus using chess symbols from an actual chess-position problem.

## META_PHRASE_PUN
Use state narration and phonetic resegmentation. See `meta_phrase_puns.md`.
