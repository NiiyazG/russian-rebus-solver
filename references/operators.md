# Operator grammar

## Standard operators

- letters adjacent → concatenate;
- comma left → delete N first letters;
- comma right → delete N last letters;
- leftward reversal cue → reverse;
- `A=B` → replace;
- crossed **individual letter/index** → delete that local item;
- indices → select/reorder letters;
- explicit digits may also be spoken numbers;
- notes → ДО/РЕ/МИ/ФА/СОЛЬ/ЛЯ/СИ.

## Whole-token state operator

A large X over an entire token is ambiguous:
1. standard absence/deletion;
2. meta narration: `X был/была/было/были`.

Use meta narration when supported by global puzzle structure.

## Presence operator

An intact token contrasted with crossed tokens can encode:
`X есть`.

Example:
`ПО` intact → `ПО есть` → `ПОЕСТЬ`.

## Missing-sequence operator

If a visually complete sequence omits a member:
- detect missing item;
- create absence narration;
- under `нет`, prefer natural genitive:
  `5` → `пяти`;
- test particles `-то` and discourse `а` in phrase rebuses.
