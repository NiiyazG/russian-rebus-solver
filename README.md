# Russian Rebus Solver v2.1 for Hermes

Версия 2.1 добавляет новый класс: **фразовые фонетические ребусы через состояние элементов**.

## Новый режим

`META_PHRASE_PUN`

Он нужен для ребусов, где:
- целые слоги зачёркнуты;
- другие слоги остаются "есть";
- из последовательности что-то пропущено;
- буквальное описание состояния нужно произнести вслух и затем пересегментировать.

Канонический тест:
`КО` зачёркнуто + `ЗА` зачёркнуто + `ПО` есть + нет 5
→ `КО была, ЗА была, ПО есть, а пяти-то нету`
→ **«Кобыла забыла поесть — аппетита нету».**

## Установка

Распаковать папку `russian-rebus-solver` в:

```text
~/.hermes/skills/
```

## Самопроверка

```bash
python ~/.hermes/skills/russian-rebus-solver/scripts/validate_cases.py
```

## Важное изменение приоритета

Большой X на **всём слоге/карточке** больше не считается автоматически удалением букв. Hermes обязан проверить, не является ли это состоянием "было/нет".
